## 📚 About The Project

EduVillage Smart Education System is a modern web-based academic management platform designed to simplify educational workflows and provide a centralized system for students, faculty, and administrators.

The project focuses on improving digital learning experiences through smart management features, secure authentication, attendance tracking, assignment handling, and resource management.

---

## 🚀 Main Features

* 👨‍🎓 Student Management
* 👩‍🏫 Faculty Management
* 📅 Attendance System
* 📝 Assignment Management
* 📊 Smart Dashboard
* 🔐 Secure Authentication
* 📚 Study Resources
* ⚙️ Admin Panel

## ▶️ Run Project Locally

### Activate Virtual Environment

```bash id="e2"
.\.venv\Scripts\Activate.ps1
```

### Install Requirements

```bash id="e3"
pip install -r requirements.txt
```

### Run Server

```bash id="e4"
python manage.py runserver
```
