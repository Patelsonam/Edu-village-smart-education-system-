# 📚 Project Overview

**EduVillage Smart Education System** is an advanced academic management platform built using Django and Python. The project focuses on creating a centralized digital environment for educational institutions where students, teachers, and administrators can efficiently manage academic activities.

The platform aims to modernize educational workflows by integrating automation, secure authentication, academic analytics, and smart resource management into a single system.

---

# 🎯 Objectives

* Digitize academic and administrative operations
* Simplify student and faculty management
* Provide centralized access to educational resources
* Improve communication between users
* Reduce manual paperwork and repetitive tasks
* Create a scalable smart education ecosystem

# ▶️ Installation & Setup

## 1️⃣ Navigate to Project Folder

```bash id="p5r9vt"
cd eduvillage
```

---

## 2️⃣ Create Virtual Environment

```bash id="d2k7mf"
python -m venv .venv
```

---

## 3️⃣ Activate Virtual Environment

### PowerShell

```bash id="h4x8yn"
.\.venv\Scripts\Activate.ps1
```

---

## 4️⃣ Install Dependencies

```bash id="s9v1we"
pip install -r requirements.txt
```

---

## 5️⃣ Run Development Server

```bash id="f6t3op"
python manage.py runserver
```
